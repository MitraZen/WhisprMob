# Whispr v1.2.9 Release Notes

**Version:** 1.2.9

## ✨ What's New

### 🎨 Beautiful New Welcome Screen Design
- **Pastel Color Scheme**: Soft, elegant pastel background with lavender accents
- **Improved Typography**: Enhanced app name styling with brand purple color (#7B5CF4)
- **Inspiring Tagline**: New tagline "Where whispers find hearts" with italic styling
- **Refined Feature Cards**: Soft lavender feature blocks with subtle shadows and improved contrast

### ⚡ Performance Improvements
- **Removed Heavy Animations**: Eliminated LottieView animations for better performance
- **Faster Load Times**: Welcome screen now loads instantly without animation delays
- **Reduced Bundle Size**: Smaller app size due to removed animation dependencies
- **Better Responsiveness**: Improved touch responsiveness and smoother interactions

### 🎯 User Experience Enhancements
- **Cleaner Interface**: Simplified design focuses on essential elements
- **Better Visual Hierarchy**: Improved spacing and typography for better readability
- **Enhanced Button Styling**: Updated primary button with brand colors and improved shadows
- **Consistent Branding**: Unified color scheme throughout the welcome experience

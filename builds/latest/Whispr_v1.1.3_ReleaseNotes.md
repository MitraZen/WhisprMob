## Installation Instructions

### For Google Play Store (AAB)
- Upload the `.aab` file to Google Play Console
- The file is optimized for Play Store distribution
- Supports dynamic delivery and smaller download sizes

### For Direct Installation (APK)
- Enable "Install from Unknown Sources" on your Android device
- Download and install the `.apk` file directly
- Perfect for testing or sideloading

## System Requirements
- Android 6.0 (API level 23) or higher
- Minimum 2GB RAM recommended
- Internet connection required for core functionality
